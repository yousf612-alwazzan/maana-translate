الفصل ١

شوف الفرق

اللقطات من تجربة حقيقية بنموذج ذكاء اصطناعي، على رسمة وصفحة صنعناهم للاختبار.

الفصل ٢

التثبيت في أربع لقطات

المتصفح ما يسمح لأي برنامج يضيف إضافة بنفسه. فالمثبّت ينسخ الملفات، ويمشي معك ثلاث خطوات قصيرة داخل المتصفح، ويجهّز لك اللي تلصقه.

شغّل المثبّت

ملف واحد صغير. اختر متصفحك واضغط «ابدأ التثبيت».

ويندوز يحذّر لأن الملف مو موقّع: More info ثم Run anyway.

افتح صفحة الإضافات

اضغط «افتح المتصفح»، ثم Ctrl + V في شريط العنوان و Enter.

العنوان منسوخ لك جاهز.

وضع المطوّر

شغّل مفتاح Developer mode في زاوية الصفحة.

حمّل الإضافة

اضغط Load unpacked، ثم Ctrl + V واضغط Select Folder.

المسار منسوخ لك جاهز.

الفصل ٣

اربط مفتاحك

الإضافة تشتغل بمفتاحك إنت من مزود الذكاء الاصطناعي اللي تختاره، مثل Google Gemini.

وافق على البداية

صفحة الإعدادات تفتح بعد التثبيت. اضغط «موافق».

سوّ المفتاح

عند Google Gemini اضغط «افتح صفحة المفتاح» وسوّ مفتاح بحسابك.

الصقه واختبره

اضغط «اختبار». إذا رد عليك بجملة مترجمة فكل شي جاهز.

ترجم

Alt + M لصور المانجا، و Alt + T للصفحة. نفس الاختصار يرجّع الأصل.

الفصل ٤

الخصوصية

وين تروح صفحاتي؟
  • الإضافة ما تجمع أي بيانات عنك، وما عندها سيرفر ولا إحصائيات ولا إعلانات.
  • النص أو الصورة اللي تطلب ترجمتها تنرسل من متصفحك مباشرة للمزود اللي اخترته، وبعد موافقتك.
  • المفاتيح والإعدادات تبقى على جهازك.
  • للصفحات الحساسة تقدر تستخدم نموذج يشتغل على جهازك (Ollama) بدون إنترنت.
  • الكود كله مفتوح للقراءة على GitHub. سياسة الخصوصية كاملة

English

Maana is a browser extension that writes the translation inside manga and comic speech bubbles and translates web pages in place, by meaning rather than word for word. It translates from any language into Arabic or any language you pick, using your own API key from an AI provider such as Google Gemini, or a local model through Ollama. The interface is in Arabic.

  1. Download and run Maana-Setup.exe. Windows warns about an unsigned app: More info, then Run anyway.
  2. Follow its three steps in the browser: paste the address it copied for you, switch on Developer mode, press Load unpacked and paste the folder path.
  3. In the settings page, agree to the notice, add your API key and press the test button.
  4. Alt+M translates comic images, Alt+T translates the page.

Chromium browsers do not allow a program to add an extension by itself, which is why those three steps are manual. Source and releases: github.com/yousf612-alwazzan/maana-translate.
